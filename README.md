# Alpha-strings

C++ companion code for the paper [*Semimeander Crossing Number of Knots and Related Invariants*](https://doi.org/10.1007/s10958-020-05104-5). It enumerates unweighted α-strings: cyclic words with a distinguished basepoint, in which every letter appears exactly twice.

The original paper contains an error in a proof, which was subsequently corrected in [*On the complexity of meander-like diagrams of knots*](https://doi.org/10.1142/S0218216525500816). The enumeration implemented here is not required for the later argument.

**Status:** This repository is preserved for historical reference.
